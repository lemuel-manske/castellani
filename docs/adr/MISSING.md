# ADR implementation gaps

Status of the implementation against the accepted ADRs (30 ADRs, audited 2026-11-24).
Only observable gaps are listed; deferred-by-design items are noted where the ADR makes
them optional. Paths are relative to the repository root.

## 3. Implementation decisions without a compatible ADR

- **Identity generation:** Go uses `crypto/rand` hex with `run-`/`msg-`/`recovery-`/`lease-` prefixes; Capture uses UUIDv4 for attempts/snapshots and deterministic UUIDv5 keys for outbox IDs; Search uses `randomUUID`. ADR-0012 defines the envelope only, not identity generation. (`services/coordinator/adapters/persistence/dynamodb/api.go`; `services/capture/src/adapters/persistence/dynamodb/queries/task.py`; `services/search/src/adapters/persistence/dynamodb/indexing-ledger.ts`)
- **Persistence schemas:** ADR-0005 defines ownership, not keys. All tables, GSIs, TTLs and `PAY_PER_REQUEST` billing are fixed in Terraform and duplicated in service adapters; table and bucket names live as fixed topology constants in `services/capture/src/topology/`, including the non-configurable authentication-profile bucket. (`infra/terraform/main.tf`; `services/capture/src/topology/tables.py`; `services/capture/src/topology/buckets.py`)
- **Frontier keys:** `v1-` + SHA-256 of `url-v1:<normalized URL>`; the hash and version prefix are persisted identities, not covered by ADR-0025's normalization policy. (`services/capture/src/domain/capture/url_identity.py`)
- **Capacity allocation:** numbered slot rows `0..9` scanned for the first unleased slot rather than a counter/increment; ADR-0021 leaves the algorithm open but does not record this choice. (`services/capture/src/adapters/persistence/dynamodb/alloc.py`)
- **Lease/retry timings:** 60s task/browser leases, 30s outbox lease with 0.5s poll and 5s retry, renewal at one-third of remaining time; Coordinator 30s reconciliation/2m stall/5 admission retries with 30ms backoff; Search 5 delivery + 5 indexing attempts with 120s leases. ADRs 0014/0020/0021 do not fix these values. (`services/capture/src/capture/settings.py`; `services/capture/src/login/settings.py`; `services/coordinator/config.go`; `services/search/src/assembly/config.ts`)
- **Health semantics:** readiness is a serve-state flag in Go, unconditionally true in Search, and runtime-task state in both Capture processes; Search has no liveness route. ADR-0016 requires health checks but not these semantics. (`services/coordinator/server.go`; `services/search/src/api/server.ts`; `services/capture/src/capture/api/main.py`; `services/capture/src/login/api.py`)
- **Search index:** one `archive-pages-v1` index, one shard, zero replicas, document ID = `snapshotId`, refresh-disabled writes. ADR-0029 explicitly defers mappings/ranking. (`services/search/src/adapters/search/topology.ts`; `services/search/src/adapters/search/opensearch.ts`)
- **Artifact staging:** `capture-staging/{archiveId}/{urlKey}/{attemptId}/{snapshotId}/...` in one versioned private bucket with SHA-256 verification; ADR-0006 defers naming and deduplication. (`services/capture/src/adapters/artifacts/s3.py`)
- **Idempotency retention:** 48h (ADR-0010 says "at least 24h") and 8–200 character keys with control-character rejection. (`services/coordinator/adapters/persistence/dynamodb/archive-queries.go`; `libs/httpx/validation.go`)
- **Interactive session transport:** a dedicated internal `capture-login` manager serves `POST/GET/PUT /sessions`, a session-scoped browser UI, and an HTTP/WebSocket VNC proxy; Gateway routes session and browser traffic to it through `GATEWAY_CAPTURE_LOGIN_URL`. Live browsers are Playwright-managed headful Chromium under Xvfb with x11vnc/noVNC. Session metadata, idempotency keys, expiry/recovery, and generation pointers use Capture-owned DynamoDB; `context.storage_state()` is AES-GCM encrypted with an application key before S3 storage. ADR-0028 defers transport and UI details; ADR-0030 records the process boundary but not this proxy design. (`services/capture/src/login/api.py`; `services/capture/src/login/routes.py`; `services/capture/src/application/login/manager.py`; `services/gateway/api/session/browser.go`; `docker-compose.yaml`; `infra/terraform/main.tf`)
- **Auth-profile boundary:** `SessionStore` reads the run's generation/profile pointer from DynamoDB, while `EncryptedAuthProfileStore` only encrypts and reads S3 objects; callers compose the two with an `AuthProfileReference`. ADR-0015/0028 defer storage wiring, and no adapter crosses the DynamoDB/S3 boundary. (`services/capture/src/domain/login/session.py`; `services/capture/src/adapters/persistence/dynamodb/session.py`; `services/capture/src/adapters/artifacts/auth.py`)
- **Archive retrieval transport:** `/archives/{id}/pages` uses a base64url DynamoDB cursor with a one-item lookahead so the final page has no cursor, and `/archives/{id}/wacz` serves `application/wacz` with single byte ranges, `If-Range` ETag validation and 400/416 problem responses. ADR-0027 fixes replay requirements but not these HTTP details. (`services/capture/src/capture/api/metadata.py`; `services/capture/src/adapters/persistence/dynamodb/archive.py`; `services/capture/src/capture/api/wacz.py`)

## 4. Priority

1. Close the end-to-end path: route/consume `StartCrawl` → crawl termination + manifest → WACZ packaging/publication → `ArchivePrepared`/`ArchivePublished` → SAGA completion (0012/0013/0014/0023/0027).
2. Consume stored authentication generations in page workers: detect auth rejection, block only affected tasks in `WAITING_FOR_AUTH`, support renewal/continue and fence stale workers (0015). The dedicated manager and protected profile storage already exist (0028).
3. Add fault injection, F1–F8 scenarios and metrics (0018); add the missing Search outbox and compensation events (0014/0020).
4. Resolve remaining contradictions in 0012, 0013, 0020, 0021/0018 and 0026.
